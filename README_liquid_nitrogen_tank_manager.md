# 液氮罐管理程序 · 使用说明

这是由原“-80°C 冰箱管理”项目调整而来的液氮罐版本，用于管理细胞冻存盒、盒内孔位、细胞搜索和细胞库存，并保留 Excel 导入导出、备份恢复和归档等功能。

普通“查找细胞”会搜索全部未归档液氮罐，并在结果中标明液氮罐、冻存盒和孔位；打开其他液氮罐的结果时会自动切换并高亮对应孔位。从搜索结果打开冻存盒后，左上角会直接返回搜索结果；当次搜索中打开过的冻存盒会显示“已查看”并高亮卡片，更换搜索词后自动重置。包含批量移动、批量清空的高级搜索仍限定当前液氮罐，防止跨罐误操作。

## 启动

双击 `start_liquid_nitrogen_tank_manager.bat` 即可启动。程序使用本地 SQLite 数据库 `liquid_nitrogen_tank_storage.db`。

## 液氮罐盒位结构

- 每个新建液氮罐默认有 4 列、每列 5 层，共 20 个冻存盒位；需要时可为单个液氮罐添加第 5 列，扩展为 25 个盒位。
- “查找空位”可按所需冻存管数，在当前或全部液氮罐中推荐同盒连续空孔；打开结果后会自动高亮并选中推荐孔位，左上角可直接返回查找结果。当次查找中已打开的冻存盒会在结果列表中高亮标记，便于在多个推荐盒间逐个查看。
- 盒位编号由“列 + 层”组成。例如 `41` 表示第 4 列、第 1 层。
- 每个两位编号对应一个独立冻存盒位。
- 每个盒位固定对应一个细胞冻存盒，不再在盒位外层重复录入样品。打开细胞冻存盒后管理盒内孔位；默认布局为 9×9，可在 1×1 到 20×20 之间调整。
- 打开冻存盒时，程序会根据当前窗口可用宽度、高度和盒子行列数，自动选择尽可能大且可完整显示的格子比例。窗口尺寸改变后可点击“适应窗口”重新计算。
- 盒内孔位支持 80% 到 200% 缩放，通过工具栏上的“缩小”、“放大”和“适应窗口”按钮操作。为避免误触，`Ctrl + 鼠标滑轮` 不再改变格子大小。
- 放大后如果孔位表超出可视区域，会在孔位区内显示横向或纵向滚动条；可使用鼠标滑轮上下移动，或按住 `Shift` 滚动滑轮左右移动。底部图例固定显示，不随孔位表滚动。

## 主要功能

- 冻存盒位总览与使用率统计。
- 细胞名称、类别、入库日期、入库人和备注等孔位记录；每个孔位固定按 1 支冻存管统计。
- 在细胞库存中查看同一细胞的多个存放位置时，从位置列表打开冻存盒后可直接返回该列表；已查看的冻存盒会高亮标记，盒内对应孔位会同步高亮。
- 入库、出库及登记导出的日期对话框支持点击日历选择，默认为当天，也可直接手工输入日期。
- 日期面板使用独立的顶层浮窗，不受录入对话框边界限制；在高DPI或屏幕边缘会自动选择上下方的可用位置，避免日期被裁切。
- 输入法确认候选词时仅提交文字，不再模拟 Alt 等系统按键；再次按 Enter 可直接执行保存或确认，不会打开 Windows 窗口菜单。
- 出入库登记筛选区的“日期从 / 日期至”支持点击日历选择，也保留手动输入日期和 Enter 筛选。
- 盒内孔位支持批量入库、批量出库和二次确认清除；入库人、入库日期以及出库人、出库日期均写入登记。
- 批量选择和快捷移动状态仅属于当前冻存盒；只要离开当前“细胞冻存盒孔位”界面（包括返回、左侧工作台、切换液氮罐或打开其他冻存盒），就会自动退出临时操作模式并清空已选孔位。当前盒内的保存、缩放或页面刷新不会触发退出。
- “出入库登记”集中展示操作类型、细胞、原位置/新位置、人员、业务日期和系统时间，可按关键词、液氮罐、操作类型及日期筛选。
- 登记页采用 SQLite 统计和分页读取：界面最多加载最近 300 条，运行内存最多缓存最近 1000 条；历史记录在数据库中完整保留，新增登记采用增量写入而不是重写整张登记表。
- 只有普通入库和普通出库属于记名操作；清除、快捷移动、撤销移动、信息更正及历史迁入均匿名登记，不显示或保存操作人员。
- 快捷移动只作为一条“入库（快捷移动）”登记，不拆分成出库和重新入库；移动后保留细胞原入库人、入库日期、类别和备注。撤销移动同样单独留痕。
- “撤销上次移动”只在开启快捷移动时显示；未开启时不占用界面操作空间，但有效的撤销记录仍会保留。
- 按盒位、样品、实验编号、类别、人员和日期搜索。
- 批量移动、清空和导出。批量移动的起始盒位使用两位编号，例如 `11`。
- 管理多个液氮罐，并支持重命名、归档和恢复。
- 本地数据库备份与恢复。

## Excel 导入导出

主菜单“导出 Excel”只生成库存总台账，包含汇总统计、每个液氮罐的独立工作表和使用说明，不包含出入库登记。“出入库登记”页面提供独立的“导出出入库”按钮：初始日期和截至日期均默认当天，可通过日历点选或手工修改，并只生成该日期范围内的普通入库、出库记录；历史迁入、清除、信息更正和快捷移动不会进入正式登记表。

导入时只接受当前液氮罐列数范围内、且第二位为 1–5 层的盒位编号。导入前会先显示预览，且自动创建数据库备份；Excel 导入和导出本身不写入出入库登记。

## 原项目数据

原 -80°C 项目使用四位储位编号，无法无歧义地自动映射到新的 20 个两位盒位。如需迁移原项目数据，建议使用单独备份文件并手动确认盒位对应关系。
